# Drowsy's WFRP4e Ratter Implementation

Foundry VTT content module implementing fan-created WFRP material from The Ratter magazine for the
WFRP4e system.

## Mutant's Handbook Automation

Enable **Use The Mutant's Handbook mutation rules** in Module Settings to replace the standard
Dissolution of Body and Mind aftermath with the Ratter #11 rules. Rolled mutations are posted as
draggable Items, and their supported acquisition choices, grants, tests, actions, and effects run
when the mutation is added to an Actor. Any decisions left to the table are noted on the relevant
Item.

The WFRP4e Core Rulebook content module is required for Core grants. Winds of Magic is recommended
for the optional Augury and Psychometry grants.

Install or update the module with this manifest URL:

```text
https://github.com/jeremyglebe/Foundry.Warhammer.Ratter-Implementation/releases/latest/download/module.json
```
